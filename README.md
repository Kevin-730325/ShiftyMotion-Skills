# ShiftyMotion Skills

**把产品界面，变成丝滑的动效视频。**

UI Demo Motion v3.2 是面向 AI Agent 的 UI 动效制作技能包。你提供参考片、产品素材与需求，Agent 按参考拆解、镜头编排、交互反馈、光效与声音设计流程，制作视频并检查成片。

支持 **After Effects** 和 **HTML / JavaScript** 两条路径。根据目标选择工具，不强制绑定某个框架。

## 你给它什么，它给你什么？

| 你提供 | 你获得 |
| --- | --- |
| 参考视频或风格方向 | 参考分析、镜头与交互编排 |
| Logo、UI 素材、截图、文案 | 与品牌匹配的 UI 动效 |
| 时长、比例、软件与声音要求 | MP4，以及按需交付的 AEP 工程或网页源码 |

适合产品功能片、软件宣传片、操作教程、功能发布与短视频演示。Skill 是制作方法和工具资产，不是独立视频软件；需要能读写文件、执行代码或操作所选软件的 Agent。

## 安装

下载本仓库：右上角 **Code → Download ZIP**，解压后找到 `skills/ui-demo-motion/`。

最简单的方法：将完整文件夹交给你的 Agent，并发送：

> 请把这个 ui-demo-motion 文件夹安装到你支持的技能目录。保留 assets、references、scripts 和 SKILL.md 的完整结构，安装后确认可以调用。

不要只复制 SKILL.md，音效、参考和辅助脚本也属于技能包。不同 Agent 的技能目录和调用方式以其自身说明为准。

## 开始制作

在支持技能调用的 Agent 中选择 **ui-demo-motion**，或明确让它读取本包的 `SKILL.md`。可直接使用下面的模板：

```text
例子：
请使用 ui-demo-motion 制作一支 UI 动效视频。

参考：附件视频的前 10 秒，尽量匹配构图、节奏和转场。
素材：使用我提供的 Logo、UI 图层与图片。
内容：把品牌与文案替换为【你的产品和文案】。
风格：紧凑丝滑，打字自然，按钮有按压与光效反馈，
镜头有变速推拉和适量纵深，重要文字保持可读。
技术：使用 HTML + JavaScript；如需 AE，请改为 AE。
声音：添加与交互同步的音效，不加背景音乐。
交付：1920×1080、60fps 的 MP4，附源码或可编辑工程。
只在缺少关键信息时询问，其余自行判断并完成检查。
```

自由创作时，将第一行参考要求改为“借鉴风格，重新设计镜头和布局”。修改时指出具体秒数、对象和期望变化，会比“再丝滑一点”更有效。

## 包含什么

- **参考拆解与对照**：入口、构图、节奏、转场、镜头和关键帧检查。
- **19 种动作配方**：文字、卡片、打字、指针、按钮、扫描、结果展示等。
- **镜头与层次**：变速推拉、甩镜、视差、三维层次与运动模糊。
- **分层光效**：Logo 条形显现、点阵扫光、按钮反馈、清晰核心与柔光。
- **83 个短音效，8 类事件**：点击、悬停、转场、成功、错误、警告、通知、实验效果，附试听页与索引。
- **交付检查**：随机定位、重播、同步、完整解码，以及画幅、帧率和音轨检查。

## 选 AE 还是 HTML？

| 路径 | 适合 |
| --- | --- |
| After Effects | 需要原生 AEP、复杂摄像机、多层合成和后续人工精修 |
| HTML / JavaScript | 需要网页预览、程序化动画、快速修改与逐帧导出 |

可按需要选用 Canvas、SVG、GSAP、Remotion 或 WebGL，不需要全部安装。AE 需要本机软件；网页导出依具体实现准备运行时及编码工具。速度和 token 消耗取决于任务复杂度、素材及返工次数，不保证某条路径始终更省。
