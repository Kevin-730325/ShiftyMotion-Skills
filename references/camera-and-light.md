# 连续镜头、纵深与精致光效

以下为跨软件视觉方法。数值除标注「已用」外均为调校起点，以 1080p 画面说明；不是测得的参考原工程参数。不要把配方全部堆进同一镜头。

## 1. 拖拽感、甩镜与持续运动

镜头按注意力移动：全貌 → 输入细节 → 提交按钮 → 反馈接管 → 新界面。预先指定世界坐标中的焦点，不逐层补偿位置来假装相机移动。

一段甩镜可拆成「轻预备 → 短加速 → 主要位移 → 小过冲／回收 → 沿主方向慢移」。过冲来自镜头惯性，不是每次套弹簧。最近案例主位移约 0.1–0.25s，回收约 0.1–0.2s，随后保留较慢运动；具体时点仍以参考为准。

- 横向位移时短暂小角度滚转或注视点滞后，回收后趋于清晰。没有参考依据不要持续摇晃。
- 展示同一状态较久时，可轻推近、沿内容浏览或让下一对象预备入场。速度要变化，避免长期匀速漂移；不要为了「不停」让观众读不完字。
- 连续段不要把所有关键帧都设成零速度。检查位置曲线之外的速度与相邻段方向；视觉上不应每隔一秒停车。
- 镜头动、图标局部旋转、UI 抬起分别管理，防止父子变换叠加成双倍移动。跨镜匹配目标在画面中的位置、大小、主运动方向和亮度。
- 相机位置与注视点可有很短的滞后形成拖拽感；最近案例用过 0.008s 的位置取样差，只是已用实现，不是所有素材的固定规则。

## 2. 三维空间与景深

相机参与局部展示及转场；用户要求全程摄像机时，每个相关场景使用实际相机，可以分镜而不强求单台从头跑到尾。

背景、主体面板、浮起的结果卡、光标／强调层按用途放置 Z 间距。阅读面尽量接近正视，小角度倾斜、接触阴影和相机移动产生的视差已经能给出纵深。AE 中朝镜头方向的 Z 值取决于相机方向，不硬编码所有工程的负 Z。

景深只软化不重要的前后层，焦平面跟随目标面板；大光圈把正文糊掉通常得不偿失。运动模糊表达速度，景深表达距离，背景低频光表达氛围，不能用统一高斯模糊顶替全部。

## 3. Logo 分条发光与格子立体底板

从后向前拆为：接触阴影 → 金属厚度／边缘反射 → 深色圆角面板 → 低对比格子 → 原始 logo → 清晰光芯与柔光。

- logo 保留真实矢量路径。用多个窄条遮罩错峰揭示同一个 logo，可从一侧扫入；每条独立定时，最后完整显现。不是对每条添加任意矩形以致变成假 logo。
- 最近已用 8 条遮罩、约 0.037s 行间错峰、约 0.22s 单条展开。条数取决于 logo 和目标尺寸，不把数值作为固定风格。
- 金属底座用几层窄厚度、明暗渐变、细边高光和局部偏蓝反射构造。平面叠层是 2.5D 材质近似，不能声称物理渲染金属；若参考要求显著视角变化，再考虑实际几何／3D 软件。
- 底板网格受圆角裁切，低于 logo 的视觉亮度。亮条、格子、logo 和光晕跟随同一坐标系统；检查遮罩边缘缝隙与局部双倍曝光。
- 图标组装可先显示金属轮廓与横向亮条，再让完整彩色面板接管；局部翻转与整体移动错开峰值。

## 4. 按钮反馈与点阵波

按参考选择阶段：按下缩小 → 单次回弹 → 箭头／状态图标变化 → 光芯变亮 → 点阵沿曲面扫出 → 粗光环扩张 → 下一镜接管。普通按钮不必执行完整链。

点阵应有传播前沿。可按到发光中心的距离控制到达时间：`arrival = trigger + distance / waveSpeed + smallDeterministicOffset`；每点短时亮起并衰减，不能让整张网格同时闪烁。若参考是扫光，使用沿路径的距离而不是径向距离。

光效拆成四类：

1. 清晰核心：小点／边缘，保护形状。
2. 近场 bloom：较小半径，让发光来自表面。
3. 宽柔光：更低透明度，强调周围受光。
4. 扩散环：有厚度的独立轮廓及多尺度柔光，承担转场。

面板内的点阵与宽光洗必须用同一个圆角轮廓裁切；面板外扩散环单独分层。检查局部光先亮、波前后到的因果。过亮会吞掉按钮，过厚的环会挡住下一场景；优先校光形、峰值面积与时序，再加粒子。

## 5. 文字与背景光

字符显现可短暂上移、透明度增长、轻微去模糊，随后恢复稳定清晰。品牌短字或关键标题允许柔光副本，正文保持清晰核心；不用所有字永久外发光。详见 [打字实现](typing-and-interaction.md)。

可复用背景家族：近白细点阵、炭黑点阵、深色绿色低频波动光、少量局部视差点。先保证主体读得清，光波缓慢变化方向／尺度／亮度，别变成高频闪烁。动背景在当前引擎中分层构建便于调色；静态 AI 背景只能作为位图素材，不称为全矢量或可拆灯光。
