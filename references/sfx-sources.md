# 在线补充与来源

## 固定素材优先，网站补充

本次随包 83 个 WAV 仅约 2.2 MiB，优先本地使用：可离线、确定性重播、不会因为网站刷新换掉音色。库中没有适合的声音时，才访问 https://procedural-sounds.vercel.app/ 。

本次查看网站页面，可见 tap、hover、transition、success、error、warning、notification、experimental 类别；支持浏览器生成／试听、Export WAV、Copy sound 和 Copy player。网站提示仍在 beta。它不是已确认可通过文件名搜索并重新下载任意旧声音的固定资源 API。

按需流程：选择事件类别 → 生成少量候选并试听 → 合适后 Export WAV 到当前项目 → 记录来源、类别与文件哈希。若使用网页实现，可以用 Copy sound 保存声音 recipe，同时保存 Copy player 的运行代码；确认当前可用接口，不假设已有 npm 包或虚构下载 URL。页面或工具不可用时继续使用随包音效，不把整个视频任务卡在在线生成上。

下载来的短音效先检验时长、采样率、声道、切口与音量。固化到项目资产后再配声，避免播放时每次重新生成。AE 优先使用 WAV；网页可以用 WAV 或已验证的 recipe+player。只把运行代码带进网页方案，AE 项目不依赖浏览器实时发声。

## 来源记录

用户说明这批文件大部分来自上述网站，逐文件的生成记录／recipe 未提供，因此 manifest 标记为用户提供、可能来自该站；不能把全部文件称为本次原创合成或全部已验证来源。原名与 SHA-256 均保留。网站的开源说明不自动补全每个用户文件的授权记录；需要对外分发时按实际来源与许可处理，不凭文件短就宣称无版权限制。

本版以用户指定 v3.0 文件夹为底稿，只添加这次 83 个文件及音效工作法；未附带之前的 Ocular 商业库，也未混入 v3.1 的 64 个程序合成草稿。历史参考分析仍是画面／波形证据，不能升级成原片音色识别结论。
