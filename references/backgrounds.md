# 背景选择与运动

## 来源优先级与选择

用户指定素材/色系/既有背景优先；没有指定且尚未授权自主选择时，简短询问：“有心仪背景吗？可以用你提供的、随包库、重新创作，或外部素材；要静止还是轻微运动？”可与 UI 真实性问题一起问。用户说“你定”时无需再审批。

随包 `assets/backgrounds/index.html` 可离线打开选图；`manifest.json` 记录编号、尺寸、建议、相对路径和 SHA-256，`contact-sheet.jpg` 是总览。15 张独立背景以无损 WebP 保存；`reference-overview.webp` 是用户提供的拼图参考，不是第 16 张可直接铺满的独立背景。

支持 AI 新图、程序化网格/渐变/光场、用户外部素材与可用图库。生成图用当前可用图像工具；素材不足时提出方向，不虚构已生成文件。外部来源记录链接与许可信息，保留对来源不确定性的说明。不要把绿色默认当品牌色；匹配当次品牌、明暗与文字对比。

## 静态图变动态：先确认的三项

- **是否动**：纯静态、轻微氛围、随镜头视差，或明显波动。教程长文本优先静态/低强度。
- **速度与强度**：慢/中/快比具体参数更好回答；示例慢为 8–16 秒一个光照周期，中为 4–8 秒，快速扫光只用于短转场。这些是设计起点，不是每个项目固定值。
- **效果**：柔光呼吸、横向扫光、渐变流动、网格波动、粒子、浅视差；位置/颜色/频率、是否循环、是否随音乐或点击响应。让用户选效果而非堆满全部特效。

信息板/长文字背后减少速度、光强和高频纹理；主体运动强时背景弱，UI 落位后可继续轻漂而不抢焦。边缘与画幅留超扫余量，避免推拉露边。

## 实现与可编辑性

单张位图 没有独立光层、网格层或真实 Z 深度。整图轻推和漂移可直接做；要局部波动、独立点阵或分层光效，需要程序化重建、单独光层、蒙版或可用的位移方案。不可把亮度呼吸声称为三维波动。

AE 可使用独立背景预合成、低幅渐变/噪声驱动的位移、光层与柔光，点阵按需重建。HTML 可用 Canvas/SVG/CSS，复杂光场可选 WebGL；按最终观感与渲染成本选，不强制库。时间统一接入 `render(t)` 或 AE 秒制表达式；循环需要相位闭合，测试首尾，噪声必须确定性。

先做主体叠加的短预览验证可读性；仅在用户要求风格确认或有关键未决选择时等待确认。交付注明静态源图与新增动态层，并把所用背景文件一起打包，路径保持相对。

## 轻量包的格式兼容

背景使用无损 WebP，分辨率和解码像素与 PNG 源图一致。网页可直接使用；目标 AE/其他软件若不能直接导入 WebP，在项目素材目录中先使用 Pillow 或 FFmpeg 无损转为 PNG，再导入，不需要安装额外渲染插件。转换结果随工程打包。不要把格式转换当成重新生成背景。
