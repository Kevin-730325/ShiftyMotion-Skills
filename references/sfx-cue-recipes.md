# 声音编排与 AE／网页落地

在一份 cue 表中保存 `eventId, family, variant, visualTime, anchorSeconds, startSeconds, gainDb, pan, playbackRate, bus, provenance, reviewStatus`。画面重定时后从事件重新计算 startSeconds，不能拖画面后把声音留在原位。

这些是编排方案；按新库的类别先试听选样，没有合适素材时按需补充，不能假设每个组合都有对应的现成 WAV。

## 可复用组合

| 动作 | 分层顺序 | 需要克制的地方 |
|---|---|---|
| 短语打字 | 首词 2–4 枚轻键 → 密度变化 → 停顿 → 最后收句 | 音频与字符增长对齐；停顿不继续循环 |
| 菜单到标签 | 展开轻空气 → 选中点 → 标签卡扣 | 空间小，不要大冲击和长混响 |
| 附件拖入 | 拾起 → 中段可选弱空气 → 槽位接触 → 尾巴 | 抓取和落位是重点，拖拽全程不必响 |
| 容器扩高 | 柔展开 → 内部元素稀疏点 → 停止 | 展開噪声不能压住键击与旁白 |
| 卡叠归档 | 2–3 枚轻摩擦 → 最后磁吸 | 按组配声；不每层一声大撞击 |
| 光效生成按钮 | 干触点 → 回弹可选 → 点阵前沿 → 光环空气 | 蓄能只在画面有预备；最多一个主重音 |
| 横向甩镜 | 弱前导 → 速度峰 whoosh → 回收短尾 | 保持方向；避免前后都用冲击形成两次刹车 |
| 快速推近 | 细空气逐渐打开 → 速度峰弱低体 → 近景清晰停止 | 不给持续微推长 whoosh |
| logo 分条组装 | 少量扫描颗粒 → 完整形态的小亮尾 | 亮条密集时按组，不每条发声 |
| APPS／短标题汇字 | 3–4 枚微错峰点 → 一次合拢落点 | 不把正文做成敲木鱼；最后声音身份统一 |
| 结果矩阵 | 首卡落点 → 中间弱点／留空 → 末次确认可选 | 不把大量结果变成打击乐 |
| 大光环换场 | 可选短蓄能 → 空气扩张和弱低频 → 新场景干落点 | 与音乐鼓点择一作主冲击 |

## 十秒片段的配声密度示例

这是新配声模板，不是从参考分离出来的 cue 时间：
- 0–1.6s 品牌组装：少量细扫描、字标汇聚、一次轻亮尾，避免 logo 和 APPS 各打一个大重音。
- 2.3–2.6s 输入特写：短 whoosh 与速度峰配合，进入正文后降低运动总线。
- 2.6–4.0s 输入：按真实字符事件形成短簇，不能整段固定键盘循环。
- 4.1–4.4s 横甩至按钮：另一个较窄的扫声，声像随方向，别机械重用片头声音。
- 4.45–5.4s 提交：触点 → 微回弹 → 颗粒传播 → 光环释放；低频只在扩散主峰一次。
- 5.5–7.3s 新状态／数值：短扫描／稀疏步骤点，镜头变化处空气即可，勿把未知状态伪造为真实成功音。
- 7.35–10s 信息条到完整界面：小落位、横向掠过、一次界面抬起收束。

由此形成「细节密集 → 空气过渡 → 清楚触点 → 留白」的变化，而不是十秒连续填满音效。

## AE

- 音频分为 typing、interaction、motion、light、impact、ambience、voice、music 等总线／预合成；不是把合成音轨烘成一个不可修改文件。
- 按 cue 的样本锚点放置 WAV，关键事件设标记；相机重定时同改声音。音频内部可亚帧定位，视频事件仍参考当前帧率。
- 音量自动化保留短过渡，点击主体不被淡入吞掉。重音附近检查多层叠加，不能仅看每个 WAV 都没削波。
- 调速度会改变音高；要保持音高时使用已验证的时间伸缩并重测锚点。音高与时长不是一个旋钮。
- 图层变为 3D 并不会自动让声音产生合适的三维声像／距离感，需要独立设计并试听。

## HTML／Canvas／Remotion

- 与画面共享秒制 cue，用 Web Audio 小窗口预排。播放、暂停、seek、重播时取消旧 source 并重建游标，不追补历史声音。
- 以固定 seed／eventId 选择变化版本；随机 seek 和离线导出要选同一个样本，不能每播放一次换一套。
- 合理限制并发同家族音源，长正文按短簇合成，防止上百 oscillator 或 sample 重叠。关闭 SFX 时同时取消已排队声音。
- 预加载解码；样本音量相对级别来自实际混音。音效总览不是成片混音，不能直接铺满视频。
- 离线导出按同一时间表混音，再复核 mux 后的声画，不录制浏览器卡顿作为最终音轨。

## 替换成更精细的素材

按动作和材质选授权样本，或用可用生成器一次生成一个原子声，再做少量变体。提示词描述声学结果，例如：`short dry tactile click, rounded transient, muted body, clean short tail, isolated, no speech or music`。运动声标明时长、前导与峰值位置；不要用一长段“酷炫科技音效”替代精准 one-shot。

声音来源分为原片混音参考、授权素材、新合成和新生成，逐条记录；人声/音乐/SFX 混合切片只能当参考试听，不能标成干净可分享音效。
