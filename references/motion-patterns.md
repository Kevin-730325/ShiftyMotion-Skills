# 动作模式与参考证据

来源：用户于 2026-09-12 提供的 8 段 UI 动效录屏；完成全段顺序抽帧、7 处转场细拆，其中两处每 1/30 秒连续检查。以下规律来自画面观察，未获得源工程。技能可独立使用，不依赖原文件永久存在。

## 可复用动作模式

| 用途 | 动作编排 | 落点与限制 |
| --- | --- | --- |
| 参考图进入 | 缩略图先进入槽位并收稳，随后调整文字区域、开始输入 | 图像保持比例；槽位与标签不互相遮挡 |
| 生成反馈 | 提交按钮回应，输入区局部反馈，结果容器从附近展开 | 保留输入语境；用真实素材填入结果 |
| 结果接管 | 结果可辨认后，输入退出；结果扩大成为主画面 | 放大前后对象能追踪，避免无关截图硬换 |
| 多结果展开 | 原画面后退，第一张引出布局，其余错峰跟进，旧输入最后退出 | 三张不同结果不是把原图机械切成三片 |
| 卡片归组 | 近处大卡移动并缩小到后方，下一张在其收稳前进入 | 用遮挡与比例建立层次，重要文本最后清晰 |
| 参数或名称变化 | 行位置保持稳定，局部替换或短距离揭示新文字 | 小变化不强行附加整屏转场 |
| 从工具到成果 | 工具局部 → 带工具位置的全景 → 结果近景 | 镜头移动给出位置关系，不反复无目的推拉 |

## 建议节奏起点

这些数值是制作建议，不是反推出的原作者参数。文字量、镜头行程、总时长和当前作品风格优先。

| 动作 | 秒 | 30 fps 近似帧数 |
| --- | --- | --- |
| 点击、提交反馈 | 0.13–0.20 | 4–6 |
| 小卡片主要位移 | 0.27–0.40 | 8–12 |
| 同组启动间隔 | 0.10–0.20 | 3–6 |
| 全界面与局部之间镜头移动 | 0.47–0.67 | 14–20 |
| 前后动作交叠 | 0.13–0.27 | 4–8 |
| 简短关键结果停留 | 0.60–1.00 起 | 18–30 起 |

长提示词不适合按最后一行的最短值快速扫过。可展示输入过程和关键词，让观众理解操作，完整提示词另供阅读；需要逐字阅读时延长停留。

## 两处时间证据

### 三张竖版结果展开

录屏 01.22.32，18.450 秒起抽样 31 帧，间隔 1/30 秒。

- +0–4f，18.450–18.583s：原画面、输入框与生成反馈仍在。
- +5–8f，18.617–18.717s：原画面缩小后退，左侧竖版卡开始露出。
- +9–18f，18.750–19.050s：左侧逐渐清晰，中间与右侧从上方陆续进入；旧画面仍位于前方。
- +19–23f，19.083–19.217s：三张结果可辨认，原画面与输入框向下退出。
- +24–30f，19.250–19.450s：旧内容离开，三张竖版收稳。

主转换约 18.62–19.38 秒，约 0.76 秒 / 23 个项目帧。关键是交叠与视觉主次，而不是让三张卡同时弹出。

### 前景卡片进入卡组

录屏 01.09.12，1.130 秒起抽样 25 帧，间隔 1/30 秒。

- +1–7f，1.163–1.363s：第一张大卡从底部进入，倾斜且带运动模糊，上移并缩小。
- +8f，1.397s：第一张已清晰，第二张已从底部进入。
- +12f，1.530s：第二张接近叠放位置，第三张启动，背景开始变亮。
- +15–20f，1.630–1.797s：后续卡片进入，同时完成背景变化。
- +22–24f，1.863–1.930s：前排卡清晰，卡组形成。

整组约 0.8 秒；第一张大幅移动到清晰落点约 7–8 个项目帧。数值由抽样估计，不代表精确关键帧区间。
