# 融合来源与证据级别

以下保留 v2.0.1（2026-09-14）的来源记录。本记录描述 v3 初期的演进，新增 AE 实作、参考精细复刻和用户反馈见 [v3 制作经验](v3-production-notes.md)。对外技能标识为 `shifty-motion`。

## 纳入的三部分

1. 原有 UI 演示动效技能：8 段早期录屏、16 段有声参考的抽样图文分析、交互节奏与品牌约束。保留原图证和证据边界。
2. 用户提供的 Claude `higgsfield-motion`：吸收 UI 主体感、19 类动作词汇、缓动思路、短语打字、附件落位、聚焦与结果接管。附其 10 张帧条供查看，没有把整份文档的绝对规则原样叠加。
3. HTML 实作：真实截图输入揭示、DOM 分层、秒制渲染、音效与媒体时钟、预加载、字节范围服务及暂停/跳转清理。实际网页完整版 106.9s、精简版 56.6s 均完成浏览器通播；该次完整版刷新间隔中位约 16.7ms，仅代表当时设备/浏览器条件。

## 刻意不作为强制要求的内容

- 「每次入场都模糊」「每段都白闪」「每镜必须短于 3 秒」「固定 85BPM」改为可选风格配方。
- 「处理过程要填满扫描和勾选」受实际产品证据限制，不能编造能力与状态。
- 广告中的无旁白/强音乐偏好不覆盖用户明确要求的教程旁白；精简时同步缩短台词。
- 不把第三方文档写出的精确测量、响度、声源与“每条视频都有”当成我们已经验证的原片事实。

## 声音与素材

历史版本未附带音效文件；v3.2 附带用户提供的 83 个短 WAV，见 sfx-design.md，也不要求参考特定音效素材；保留音效设计与同步方法。

参考图只用于分析和比对，不是目标产品原始资产，也不作为给别人的品牌素材授权。分享包不包含用户的完整录屏、人物资产、旁白、成片或 ChatCut 工程；无需访问原作者电脑即可读取技能。
