# ShiftyMotion Skills：两套制作需求模板

复制一套，替换方括号。没有偏好可写“你决定”；已提供的材料无需重复描述。模板帮助把意图说清，不是强制表单。

## 模板一：高保真复刻

```text
请使用 ShiftyMotion Skills（shifty-motion）复刻一支 UI 动效视频。

【参考与范围】
参考：附件/链接【文件】；只做【00:00–00:10】。
目标：【尽量接近原片 / 重点匹配指定镜头】。
保留：构图比例、对象进出顺序、打字节奏、镜头方向与变速、
按钮状态链、光效形态、运动模糊、转场交接与声音触点。
不需要的部分：【例如后续软件操作界面】。
先原速观看并拆解关键状态和转场前后帧；必要时检查逐帧时间戳，
按原片真实动作时间建事件表，不把所有动作统一套一种缓动。

【替换清单】
品牌/Logo：【原对象 → 我的对象，附 SVG 等素材】。
文案：【逐条原文 → 替换文案；大小写、换行、不可改内容】。
图片/结果：【原位置 → 指定文件】。
配色：【沿用参考 / 指定色值 / 适配我的品牌】。
其他部分：【保留参考 / 允许调整的范围】。

【UI 真实性：选一项】
A 严格真实 UI；已提供【组件/Figma/SVG/截图/录屏/网页】。
B 可以按参考外观重绘，但【文案/布局/流程】必须保留。
C 可以做概念界面，必须表达【功能与结果】。
如选 A 但材料不足，开始前告诉我需要什么，
可让我提供素材或选择授权网页采集，不必默认经过 Figma。
截图允许作为位图；我对真矢量和文字可编辑的要求是【要求】。

【背景】
使用【我的文件 / 随包编号 / 原创 / 外部来源 / 你推荐】。
背景【静止 / 轻微运动 / 按参考】；速度【慢/中/快】，
效果【波动柔光/点阵扫光/漂移/视差】、强度【低/中/高】。
保持主体与文字清楚；不指定时先给少量适配方向。

【声音】
音效：【参考音轨复用（我提供并允许使用）/重新配声/无】。
音乐：【指定文件/新配乐/无】；旁白：【文件/文案/无】。
不要把“音乐不变”理解成只配一个类似曲风；无法复用时明确说明。

【交付与自主范围】
时长【10 秒】，画幅【16:9】，尺寸【1920×1080】，帧率【60】。
软件【AE/HTML+JavaScript/你按效果判断】。
交付【MP4 + 可编辑工程或源码 + 必要素材】，额外要求【透明/循环等】。
请只询问关键缺项；已确认的不再问，工具与细节由你判断。
最终原速检查并提供同时间关键帧对照，说明品牌替换与仍有差异处。
```

## 模板二：原创／只借鉴风格（可完全没有参考片）

```text
请使用 ShiftyMotion Skills（shifty-motion）设计一支原创 UI 动效视频，
不要求逐镜头复刻。技术与视觉细节可以自行判断。

【目的与受众】
产品/项目：【名称及一句话用途】。
观众：【新用户/客户/开发者等】；发布位置：【平台/发布会/官网】。
希望观众看完记住或完成：【核心信息/行动】。
类型：【功能宣传/真实操作教程/概念展示】。

【内容与叙事】
必须出现的内容按优先级：【A、B、C】。
需要展示的操作与结果：【进入页面 → 输入 → 点击 → 出现结果】。
文案：【准确文本；哪些可由 AI 精简】。
结尾：【Logo/口号/行动按钮/无】；不允许出现：【内容】。
可以重新安排镜头与时长，但不能改变真实功能和关键文案。
没有完整脚本时，请根据目标设计画面逻辑，不强行补长旁白。

【参考是可选的】
参考：【没有 / 视频或图片链接】。
如果有，只借鉴【节奏/光效/镜头/配色/材质】，
不要照搬其品牌、界面和整套镜头。偏好的关键词：【简洁/科技/柔和等】。
不喜欢：【频繁闪白/过度倾斜/长时间停顿等】。

【素材和 UI 真实性】
已有素材：【Logo/品牌色/字体/产品图/截图/录屏/组件/网页链接】。
UI 选择：【严格真实 / 可按外观重绘 / 可设计概念 UI / 本片不展示 UI】。
没有组件且要求真实时，先说明截图、录屏、授权网页采集的差别，
让我选择成本合适的方法；Figma 和整站采集都不是必选。
允许自创的部分：【背景/信息板/装饰/示意界面】。

【背景与运动】
背景来源：【我的文件/随包库/原创/外部/你推荐】。
明暗及颜色：【偏好/跟随品牌】。
背景是否运动：【静止/轻微氛围/明显波动/你建议】，速度与强度【偏好】。
运动方向：【紧凑连续，适量甩镜与纵深/克制清晰的教程/其他】。
阅读重点：【哪些文字或操作需看清】，不把“不停顿”做成全程高速。

【声音与交付】
音效【要/不要】；音乐【要/不要/已有文件】；旁白【要/不要/已有文件】。
时长【约 15 秒/你建议】，比例【16:9/9:16】，帧率与尺寸【要求/你定】。
交付【MP4/AE 工程/网页源码】，可用软件【条件/不限】，截止时间【可选】。
请先用简短制作摘要记录核心顺序、UI 方案、背景和声音选择。
只把影响真实性或交付的缺项集中问一次，其余直接设计、实现并检查。
```

## 简短修改模板

“【时间段】的【对象】现在【问题】，改为【动作/强度/节奏】，
保留【已满意内容】；声音对应【触点】，不要改其他已确认镜头。”
